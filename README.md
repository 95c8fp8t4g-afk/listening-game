# Listening Quest v2

## 변경 사항
- 2학년 1~11반 선택
- 캐릭터 선택 및 점수 기반 3단계 진화
- 점수 체계를 100점 단위 중심으로 축소
- Speaking: 마이크 클릭 시작 / 재클릭 종료
- 음성 인식 결과와 목표 문장 일치도를 기반으로 연습용 점수 부여
- 교사용 문제 편집 화면
- 대화 순서 문제: 교사가 대본을 한 줄씩 수정하면 학생 문제와 정답 순서에 반영
- 객관식/빈칸 및 Speaking 목표 문장도 교사 화면에서 수정 가능
- 교사용 로컬 리포트

## 중요
현재 문제/결과는 브라우저 localStorage에 저장됩니다.
따라서 교사가 자기 컴퓨터에서 문제를 수정해도 학생들의 다른 기기로는 아직 전달되지 않습니다.
모든 기기에서 문제와 결과를 공유하려면 다음 단계에서 Supabase 같은 백엔드를 연결해야 합니다.

Speaking 점수는 전문 음성학적 발음 평가가 아니라 브라우저 Speech Recognition이 인식한 문장과 목표 문장의 단어 일치도 기반 연습용 점수입니다.
