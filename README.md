# Listening Quest v4

v4 변경사항
- 게임 종료 화면의 교사용 화면 버튼 완전 제거
- 게임 진행 중 LIVE RANKING 패널 추가
- 현재 브라우저에 저장된 플레이 기록 + 현재 플레이어 기준 TOP 5 표시
- 모바일에서는 공간 절약을 위해 TOP 3 표시
- 캐릭터 진화 시 중앙에 약 1초간 진화 팝업 표시
- 예: 🐛 애벌레로 진화! / LEVEL UP
- Speaking 점수로 진화 기준을 넘는 경우에도 진화 팝업 표시

중요:
현재 랭킹은 localStorage 기반이라 여러 학생의 서로 다른 휴대폰 점수를 진짜 실시간으로 합칠 수 없습니다.
Supabase 연결 후에는 전 학생의 실시간 랭킹으로 변경할 수 있습니다.


## v5 추가
- 교사용 리포트에 전체 / 1반~11반 필터 추가
- 전체 화면에서 반별 참여 기록과 평균 정답률 요약
- 반을 선택하면 해당 반 학생만 표시
- 학생별 최근 점수, 정답률, 캐릭터, Speaking 평균 확인


## v6 추가
- 캐릭터 진화 기준을 600점 / 1,200점으로 변경
- 정답 기본 100점
- 정답 속도 보너스 추가:
  - 5초 이내 +100
  - 10초 이내 +70
  - 15초 이내 +40
  - 20초 이내 +20
- 기존 콤보 보너스도 함께 적용
- 오답에는 속도 보너스 없음
- Speaking은 인식 정확도 점수를 중심으로 하고, 70점 이상 성공 시 속도 보너스 일부 적용


## v7 추가 — 세션별 랭킹
- LIVE RANKING은 현재 게임 세션의 점수만 사용
- 이전 플레이 기록은 랭킹에서 제외
- 이전 결과는 교사용 누적 리포트에는 계속 보존
- 교사용 화면에 `🏁 새 게임 세션` 탭 추가
- 수업 시작 전 반을 선택해 새 세션을 만들면 해당 반 랭킹이 0점부터 새로 시작

### 현재 MVP의 한계
아직 localStorage 기반이므로 '세션'도 같은 브라우저 안에서만 공유됩니다.
학생들이 서로 다른 휴대폰에서 같은 실시간 세션에 참여하려면 Supabase 연결이 필요합니다.


## v8 추가
- 본 게임 종료 후 처음 화면으로 돌아가는 버튼 제거
- 종료 학생은 '단어 뜻 맞추기' 대기용 미니게임으로 이동
- 미니게임 점수는 본 게임 LIVE RANKING에 반영되지 않음
- 교사가 최대 15개의 미니게임 단어/정답/오답을 수정 가능
- 교사용 게임 설정에서 반별 플레이 시간 선택 가능 (5~45분)
- 학생 화면에서는 플레이 시간을 선택할 수 없음
- 본 게임 점수 하향 조정
  - 정답 기본 60점
  - 속도 보너스: +20 / +15 / +10 / +5
  - 콤보 보너스 최대 +20
  - Speaking 점수도 기존보다 축소
- 진화 기준은 600 / 1200 유지

현재 시간 설정/문제/랭킹은 localStorage 기반입니다. 여러 학생 기기에서 동일한 교사 설정과 실시간 랭킹을 공유하려면 Supabase 연결이 필요합니다.


## v9 추가 — Excel 단어장 미니게임
- 미니게임 편집에서 15개 제한 제거
- 교사가 .xlsx / .xls 파일 업로드 가능
- 첫 시트 A열=영어, B열=한국어 뜻으로 자동 인식
- 헤더(English/영어, Korean/한국어 뜻 등)는 자동 제외
- 등록 단어 수 제한 없음(브라우저 localStorage 허용 범위 내)
- 학생 미니게임은 영→한 / 한→영을 번갈아 출제
- 단어장을 한 바퀴 돌면 순서를 다시 섞어 계속 출제
- 오답 선택지는 같은 단어장에서 자동 생성
- 미니게임 점수는 본 게임 LIVE RANKING과 분리


## v10 추가 — 학생 화면 카운트다운
- 교사가 설정한 플레이 시간이 학생 게임 화면에 `⏱ MM:SS` 형식으로 표시
- 카운트다운은 실시간으로 감소
- 남은 시간이 1분 이하가 되면 타이머가 강조 표시
- 시간이 0이 되면 '시간 종료' 안내를 잠깐 표시
- 학생이 현재 풀고 있는 문제까지만 마친 뒤 본 게임 종료
- 이후 자동으로 결과/대기 미니게임 화면으로 이동


## v11 추가 — 미니게임 도장 미션
- 미니게임에서 30개 연속 정답 달성 시 즉시 종료
- `도장 하나 획득!` 완료 화면 표시
- `선생님께 화면을 보여드리고 도장판에 도장 1개를 받으세요!` 안내
- 확인받기 전까지 완료 화면을 유지


## v12 추가 — 랭킹 공개 방식 변경
- 본 게임 종료 후 미니게임 시작 화면에서 LIVE RANKING 완전 삭제
- 미니게임 진행 화면에서도 랭킹 표시하지 않음
- 학생 랭킹은 교사가 `🏆 랭킹 관리`에서 공개를 켠 경우에만 표시
- 학생 화면에는 1위 / 2위 / 3위 + 본인 순위만 표시
- 교사 화면에는 현재 세션의 전체 학생 랭킹 표시
- 교사는 랭킹 공개 여부를 직접 켜고 끌 수 있음

현재는 localStorage 기반이므로 서로 다른 학생 기기에서 동일한 실시간 랭킹 공개 상태를 공유하려면 Supabase 연결이 필요합니다.


## v13 추가 — 본게임+미니게임 통합 타이머
- 교사가 설정한 총 플레이 시간이 본게임 종료 후에도 계속 흐름
- 본게임을 빨리 끝낸 학생은 남은 시간만큼만 미니게임 가능
- 미니게임 화면에도 남은 시간 카운트다운 표시
- 남은 시간 1분 이하 시 타이머 강조
- 총 시간이 0이 되면 미니게임 즉시 종료
- 종료 화면에서 `선생님의 순위 발표를 기다리세요` 안내
- 30연속 정답 도장 미션을 먼저 달성하면 기존처럼 즉시 미니게임 종료


## v14
- 본게임과 미니게임이 하나의 총 플레이 시간을 공유
- 시간이 0이 되면 본게임/미니게임 어디에 있든 자동으로 순위 발표 대기 화면으로 이동
- 교사가 `🏆 랭킹 발표`를 누르면 학생 결과 화면 공개
- 학생 결과: 1·2·3등 + 본인 순위 + 맞힌 개수 + 정답률
- 교사 화면: 전체 학생 랭킹
- 새 세션 시작 시 이전 랭킹 발표 상태 초기화

주의: 현재 localStorage 구조에서는 교사 기기의 발표 버튼을 학생들의 서로 다른 휴대폰으로 실시간 전파할 수 없습니다. 실제 수업에서 동시에 전환하려면 Supabase 연결이 필요합니다.


## v15 — Supabase 연결
- Project URL / Publishable key 연결
- 반별 게임 세션을 Supabase `game_sessions`에서 생성/조회
- 학생 점수는 `student_scores`에 upsert
- 학생별 점수/정답 수/정답률을 서버에 저장
- 학생 기기끼리 같은 세션의 랭킹을 공유
- 학생 점수 변경을 Supabase Realtime으로 구독
- 교사의 랭킹 발표 상태를 `game_sessions.ranking_published`로 공유
- 학생 대기 화면은 발표 상태를 확인해 자동으로 최종 결과 화면으로 전환
- 본게임 문제는 `game_questions`에서 읽고 교사 편집 시 서버에 저장
- Excel 단어장은 `vocabulary` 테이블에 저장/학생 기기에서 공유

주의:
현재 RLS 정책은 MVP 테스트를 위해 anon 쓰기 권한이 넓습니다. 실제 학교 배포 전에는 교사 인증과 더 엄격한 정책으로 잠그는 것을 권장합니다.


## v17 — 종료 안정화 + 교사 실시간 진행관리
- 00:00 종료 시 결과 대기 화면으로 확실히 이동
- 교사 즉시 종료 버튼 추가
- 학생별 본게임/미니게임/도장획득/결과대기 상태 실시간 표시
- 현재 문제 번호와 미니게임 연속 정답 수 표시
- 모든 학생이 본게임을 마치면 교사에게 즉시 종료 가능 안내


## v18 — 랭킹 발표 버튼 복구
- 게임 진행 중에는 최종 랭킹 발표 버튼 비활성화
- 시간 종료 또는 교사 즉시 종료 후 `🏆 랭킹 발표` 버튼 활성화
- 교사는 발표 전에 전체 학생 랭킹/점수/정답 수/정답률 확인 가능
- 교사가 발표 버튼을 누르면 Supabase `ranking_published`가 변경되고 학생 대기 화면이 최종 결과 화면으로 전환


## v19
- 교사용 현재 탭을 짙은 파랑으로 표시하도록 복구
- 랭킹 관리 탭 클릭이 먹지 않던 문제 수정 및 클릭 fallback 추가
- 랭킹 관리 화면에서 전체 학생 결과 확인
- 게임 종료 후 `🏆 랭킹 발표` 버튼 활성화
- 종료 후 교사 화면 하단에도 랭킹 발표 바로가기 표시


## v20
- 학생 플레이 결과를 Supabase `student_scores` 기반 리포트로 변경
- 리포트 1~11반 필터 및 과거 플레이 기록 유지
- 랭킹 관리 1~11반 개별 조회
- 각 반의 최신 세션만 랭킹에 표시
- 랭킹에 플레이 타임, 정답 수, 정답률 추가
- 플레이 타임은 공통 게임 시작부터 본게임 완료까지의 시간으로 저장


## v21
- 플레이 타임 저장 로직을 서버의 공통 started_at 기준으로 재작성
- 본게임 완료 시점에 play_time_seconds / main_finished_at / accuracy 저장
- 리포트를 student_scores 직접 조회 방식으로 단순화 및 평균 점수/정답률 분석 추가
- 랭킹 관리에서 1~11반 각각 조회
- 선택한 반의 `기록 전체 초기화` 버튼 추가
- 초기화 시 해당 반 student_scores, session_players, game_sessions를 모두 삭제하여 과거 리포트도 함께 삭제


## v22
- Supabase RLS/DELETE 권한 적용 후 초기화 로직 재작성
- 학급명을 기준으로 student_scores를 직접 삭제하고 삭제 성공 여부를 다시 조회해 검증
- 리포트는 join 없이 student_scores를 직접 조회하여 오류 가능성 축소
- 리포트 오류가 발생하면 교사 화면에 실제 Supabase 오류 메시지 표시
- 평균 점수/정답률/플레이 타임 분석
- 랭킹은 선택 학급의 최신 세션 기록만 사용


## v23 — 대기실 학생 강퇴
- 게임 설정 대기실에서 학생 여러 명 체크 선택
- 전체 선택 및 `선택 학생 강퇴` 지원
- 강퇴 시 session_players에서 해당 학생 입장 기록 삭제
- 학생 대기화면은 자신의 입장 기록을 감지하며, 강퇴되면 자동으로 첫 화면으로 복귀
- 복귀 후 학급/이름/캐릭터를 다시 선택해 재입장 가능
- 리포트 기능은 v22 상태 그대로 유지
