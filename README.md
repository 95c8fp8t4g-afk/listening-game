# Listening Quest v3

변경사항
- 첫 화면 교사용 진입을 작은 ⚙️ 아이콘으로 변경
- 최초 교사 진입 시 4자 이상 비밀번호 설정, 이후 비밀번호 확인
- 캐릭터 7종: 닭, 고양이, 강아지, 개구리, 나비, 펭귄, 토끼
- 모든 캐릭터 3단계 성장
- 최대 15문항 편집 가능
- 작성하지 않은 문항은 학생 게임에서 자동 제외
- 각 문항에 '학생에게 출제' 체크박스
- 교사가 대본/선택지/정답/Speaking 문장을 편집 가능

주의
현재 교사 비밀번호, 문제, 학생 결과는 localStorage 기반이라 기기별로 따로 저장됩니다.
따라서 보안용 서버 인증은 아니며, 학생 기기와 문제를 공유하려면 다음 단계에서 Supabase 연결이 필요합니다.
