# Listening Quest v4

v4 변경사항
- 게임 종료 화면의 교사용 화면 버튼 완전 제거
- 게임 진행 중 LIVE RANKING 패널 추가
- 현재 브라우저에 저장된 플레이 기록 + 현재 플레이어 기준 TOP 5 표시
- 모바일에서는 공간 절약을 위해 TOP 3 표시
- 캐릭터 진화 시 중앙에 약 1초간 진화 팝업 표시
- 예: 🐛 애벌레로 진화! / LEVEL UP
- Speaking 점수로 진화 기준을 넘는 경우에도 진화 팝업 표시

중요:
현재 랭킹은 localStorage 기반이라 여러 학생의 서로 다른 휴대폰 점수를 진짜 실시간으로 합칠 수 없습니다.
Supabase 연결 후에는 전 학생의 실시간 랭킹으로 변경할 수 있습니다.


## v5 추가
- 교사용 리포트에 전체 / 1반~11반 필터 추가
- 전체 화면에서 반별 참여 기록과 평균 정답률 요약
- 반을 선택하면 해당 반 학생만 표시
- 학생별 최근 점수, 정답률, 캐릭터, Speaking 평균 확인


## v6 추가
- 캐릭터 진화 기준을 600점 / 1,200점으로 변경
- 정답 기본 100점
- 정답 속도 보너스 추가:
  - 5초 이내 +100
  - 10초 이내 +70
  - 15초 이내 +40
  - 20초 이내 +20
- 기존 콤보 보너스도 함께 적용
- 오답에는 속도 보너스 없음
- Speaking은 인식 정확도 점수를 중심으로 하고, 70점 이상 성공 시 속도 보너스 일부 적용


## v7 추가 — 세션별 랭킹
- LIVE RANKING은 현재 게임 세션의 점수만 사용
- 이전 플레이 기록은 랭킹에서 제외
- 이전 결과는 교사용 누적 리포트에는 계속 보존
- 교사용 화면에 `🏁 새 게임 세션` 탭 추가
- 수업 시작 전 반을 선택해 새 세션을 만들면 해당 반 랭킹이 0점부터 새로 시작

### 현재 MVP의 한계
아직 localStorage 기반이므로 '세션'도 같은 브라우저 안에서만 공유됩니다.
학생들이 서로 다른 휴대폰에서 같은 실시간 세션에 참여하려면 Supabase 연결이 필요합니다.


## v8 추가
- 본 게임 종료 후 처음 화면으로 돌아가는 버튼 제거
- 종료 학생은 '단어 뜻 맞추기' 대기용 미니게임으로 이동
- 미니게임 점수는 본 게임 LIVE RANKING에 반영되지 않음
- 교사가 최대 15개의 미니게임 단어/정답/오답을 수정 가능
- 교사용 게임 설정에서 반별 플레이 시간 선택 가능 (5~45분)
- 학생 화면에서는 플레이 시간을 선택할 수 없음
- 본 게임 점수 하향 조정
  - 정답 기본 60점
  - 속도 보너스: +20 / +15 / +10 / +5
  - 콤보 보너스 최대 +20
  - Speaking 점수도 기존보다 축소
- 진화 기준은 600 / 1200 유지

현재 시간 설정/문제/랭킹은 localStorage 기반입니다. 여러 학생 기기에서 동일한 교사 설정과 실시간 랭킹을 공유하려면 Supabase 연결이 필요합니다.


## v9 추가 — Excel 단어장 미니게임
- 미니게임 편집에서 15개 제한 제거
- 교사가 .xlsx / .xls 파일 업로드 가능
- 첫 시트 A열=영어, B열=한국어 뜻으로 자동 인식
- 헤더(English/영어, Korean/한국어 뜻 등)는 자동 제외
- 등록 단어 수 제한 없음(브라우저 localStorage 허용 범위 내)
- 학생 미니게임은 영→한 / 한→영을 번갈아 출제
- 단어장을 한 바퀴 돌면 순서를 다시 섞어 계속 출제
- 오답 선택지는 같은 단어장에서 자동 생성
- 미니게임 점수는 본 게임 LIVE RANKING과 분리
